# Industrial Termimal Emulator

A C++ terminal-based emulator for industrial environments developed at university (UPC). The project simulates the management of industrial containers through a command-line interface, focusing on object-oriented programming, class relationships, data structures, and container insertion and deletion algorithms.

The application allows users to insert and remove different types of containers using interactive terminal commands.

## Overview

This project implements an industrial terminal emulator operated entirely through the command line.

The emulator represents a simplified industrial management system in which users can work with containers stored in different data structures. Each container may have attributes such as:

- Identifier.
- Size
- Status.
- Position within the terminal.

The main purpose of the project is to practice the design and management of C++ classes, as well as the implementation of insertion and deletion algorithms for different containers.

## Features

- Interactive command-line interface.

- Creation of industrial containers.

- Removal of containers by identifier.

- Search and display of containers.

- Management of multiple container sizes.

- Display of the current terminal state.

- Use of object-oriented programming principles.

- Management of containers using different data structures.

## Technologies

- C++17 or later.

- Standard Template Library.

- Command-line terminal.
